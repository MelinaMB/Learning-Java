# Ejercicios — Nivel 7: Arquitectura

## Ejercicio 1 — Capas

Diseña un mini sistema con estas capas:
- `modelo`
- `repositorio`
- `servicio`
- `controlador`

## Ejercicio 2 — MVC

Separa una funcionalidad simple de listado de estudiantes en:
- modelo
- vista
- controlador

## Ejercicio 3 — Hexagonal

Toma el caso de inscribir un estudiante y define:
- puerto de entrada
- puerto de salida
- adaptador de persistencia

## Ejercicio 4 — Microservicios

Divide el sistema escolar en 3 servicios posibles y escribe qué responsabilidad tendría cada uno.

## Checklist de Nivel 7

- [ ] ¿Sabes separar responsabilidades?
- [ ] ¿Puedes decir qué vive en cada capa?
- [ ] ¿Entiendes la diferencia entre arquitectura y patrón?
- [ ] ¿Sabes por qué una arquitectura mal dividida complica el mantenimiento?
