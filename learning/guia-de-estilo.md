# Guía de Estilo

## Nombres

- Usa nombres claros y descriptivos.
- Evita abreviaturas innecesarias.
- Prefiere `EstudianteServicio` antes que `SrvEst`.

## Ejemplos

- Un ejemplo debe explicar un solo concepto.
- Si el código se hace largo, sepáralo en pasos.
- Mantén el sistema escolar como contexto cuando ayude a entender.

## Código

- Usa indentación consistente.
- Evita duplicación.
- No mezcles demasiadas ideas en un solo bloque.
- Prefiere ejemplos pequeños antes que bloques enormes.

## Texto

- Explica primero qué se va a ver.
- Luego muestra el ejemplo.
- Al final resume en una frase corta.

## Regla práctica

Si un principiante no entiende el ejemplo a la primera lectura, probablemente hay que simplificarlo.
