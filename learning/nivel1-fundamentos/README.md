# Nivel 1 — Fundamentos de Java

En este nivel aprenderás los bloques de construcción fundamentales del lenguaje Java.
Sin estos conceptos, no es posible avanzar a los niveles superiores.

## ¿Qué aprenderás?

- Qué es Java y cómo funciona la JVM
- Tipos de datos primitivos y referencias
- Cómo controlar el flujo de un programa (if, switch, bucles)
- Cómo organizar código en métodos reutilizables
- Cómo trabajar con arreglos de datos

## Tiempo estimado

**2 a 3 semanas** dedicando 1-2 horas diarias.

## Antes de comenzar

Asegúrate de tener instalado:
- JDK 17 o superior
- IntelliJ IDEA Community o VS Code
- Ejecuta `java -version` en la terminal para verificar

¡Empecemos con [Introducción a Java](01-introduccion-java.md)!
