# Nivel 4 — Java Avanzado

En este nivel explorarás características avanzadas de Java para construir
aplicaciones robustas y de alto rendimiento.

## Temas del Nivel

| # | Tema | Descripción |
|---|------|-------------|
| 1 | [Concurrencia](01-concurrencia.md) | Hilos, ExecutorService, CompletableFuture |
| 2 | [IO y NIO](02-io-nio.md) | Archivos, streams de IO, NIO.2 |
| 3 | [Anotaciones y Reflexión](03-anotaciones-reflection.md) | Metadatos, reflexión en runtime |
| - | [Ejercicios](ejercicios.md) | Práctica del nivel |

## Tiempo estimado

**4 a 5 semanas** dedicando 1-2 horas diarias.
