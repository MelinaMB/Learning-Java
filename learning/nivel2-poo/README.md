# Nivel 2 — Programación Orientada a Objetos

La Programación Orientada a Objetos (POO) es el paradigma central de Java.
Modelamos el mundo real en **objetos** que tienen **estado** (atributos) y **comportamiento** (métodos).

## Los 4 Pilares de la POO

| Pilar | ¿Qué significa? |
|-------|----------------|
| **Encapsulamiento** | Ocultar los detalles internos y exponer solo lo necesario |
| **Herencia** | Una clase puede heredar atributos y métodos de otra |
| **Polimorfismo** | Un objeto puede tomar múltiples formas |
| **Abstracción** | Modelar solo las características esenciales |
