# Nivel 3 — Java Intermedio

En este nivel dominarás las herramientas que hacen a Java un lenguaje potente
para el desarrollo de aplicaciones reales.

## Temas del Nivel

| # | Tema | Descripción |
|---|------|-------------|
| 1 | [Colecciones](01-colecciones.md) | List, Set, Map, Queue |
| 2 | [Generics](02-generics.md) | Tipos genéricos, wildcards |
| 3 | [Excepciones](03-excepciones.md) | Manejo de errores, excepciones custom |
| 4 | [Streams y Lambdas](04-streams-lambdas.md) | API funcional de Java |
| 5 | [Optional y Fechas](05-optional-fechas.md) | Optional, LocalDate, DateTimeFormatter |
| - | [Ejercicios](ejercicios.md) | Práctica del nivel |

## Tiempo estimado

**4 a 5 semanas** dedicando 1-2 horas diarias.
