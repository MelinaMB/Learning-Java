# Mapa de Aprendizaje

## Orden sugerido

1. Fundamentos
2. POO
3. Java intermedio
4. Java avanzado
5. Buenas prácticas
6. Patrones
7. Arquitectura
8. Testing
9. Ecosistema y Spring Boot

## Dependencias importantes

- `POO` depende de fundamentos.
- `Streams` y `Optional` dependen de colecciones y lambdas.
- `Testing` depende de entender bien el código que quieres probar.
- `Spring Boot` depende de POO, testing y persistencia.

## Si quieres saltar temas

- Si ya sabes Java básico, revisa solo los resúmenes del Nivel 1.
- Si ya conoces POO, sigue con colecciones y excepciones.
- Si ya trabajas con Spring, usa este material para repasar conceptos base y buenas prácticas.

## Idea clave

No todos los temas tienen el mismo peso al principio. Lo importante es avanzar en el orden correcto.
