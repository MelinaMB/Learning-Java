# Glosario Java

## Básicos

- `JDK`: kit de desarrollo de Java.
- `JRE`: entorno para ejecutar Java.
- `JVM`: máquina virtual que ejecuta bytecode.
- `bytecode`: código intermedio generado por el compilador.
- `class`: plantilla para crear objetos.
- `objeto`: instancia concreta de una clase.

## POO

- `encapsulamiento`: ocultar detalles internos y exponer solo lo necesario.
- `herencia`: reutilizar comportamiento de una clase padre.
- `polimorfismo`: usar un mismo tipo con comportamientos distintos.
- `abstracción`: quedarse con lo esencial.
- `interface`: contrato de comportamiento.
- `abstract`: clase o método que no se completa en ese lugar.

## Java moderno

- `record`: clase inmutable corta para datos.
- `enum`: conjunto fijo de valores.
- `Optional`: contenedor para evitar `null`.
- `Stream`: secuencia para procesar colecciones.
- `lambda`: función corta y anónima.

## Ecosistema

- `Maven`: herramienta para compilar y gestionar dependencias.
- `Spring Boot`: framework para aplicaciones web y APIs.
- `JPA`: especificación para persistencia orientada a objetos.
- `JDBC`: API de Java para conectarse a bases de datos.
- `TDD`: desarrollo guiado por tests.

> Si encuentras un término nuevo, vuelve a este glosario antes de avanzar.
