# Nivel 5 — Buenas Prácticas

Escribir código que funcione es el primer paso. Escribir código que sea
**legible, mantenible y extensible** es el siguiente nivel profesional.

## Temas del Nivel

| # | Tema | Descripción |
|---|------|-------------|
| 1 | [Clean Code](01-clean-code.md) | Nombres, funciones, comentarios |
| 2 | [Principios SOLID](02-solid.md) | Los 5 principios fundamentales |
| 3 | [Refactoring](03-refactoring.md) | Code smells y técnicas de mejora |
| - | [Ejercicios](ejercicios.md) | Práctica del nivel |

## Tiempo estimado

**2 a 3 semanas** dedicando 1-2 horas diarias.
