# Git para Java

## Lo básico

- Crea una rama por cambio importante.
- Haz commits pequeños y claros.
- No mezcles cambios de contenido con cambios de estructura si puedes evitarlo.

## Comandos comunes

```bash
git status
git add .
git commit -m "Mejorar la guía de Java"
```

## Buenas prácticas

- Escribe mensajes que expliquen el motivo del cambio.
- Revisa `git diff` antes de confirmar.
- Evita commits enormes si puedes dividir el trabajo.

## Para este learning

- Un commit puede representar una mejora de un nivel.
- Otro commit puede agregar una página transversal.
- Otro commit puede corregir navegación o estilo.

## Idea clave

Git te ayuda a guardar la evolución del learning de manera ordenada y segura.
