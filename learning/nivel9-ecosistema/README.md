## Spring Boot como cierre

Este nivel reúne todo lo aprendido antes:
- Java básico e intermedio
- POO y buenas prácticas
- testing
- arquitectura
- persistencia y bases de datos

La idea es terminar con una mini aplicación completa, simple de entender y parecida a un proyecto real.
