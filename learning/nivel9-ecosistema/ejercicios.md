# Ejercicios — Nivel 9: Ecosistema

## Ejercicio 1 — Maven

Escribe una dependencia de prueba para JUnit 5 y otra para Mockito en un `pom.xml` de ejemplo.

## Ejercicio 2 — Spring Boot

Crea un controlador REST con:
- `GET /estudiantes`
- `GET /estudiantes/{id}`
- `POST /estudiantes`

## Ejercicio 3 — Persistencia

Modela una entidad `Estudiante` con JPA y define un repositorio para operaciones básicas.

## Ejercicio 4 — API completa

Diseña una mini API para:
- crear estudiantes
- listar cursos
- inscribir estudiantes en cursos
- devolver errores de validación

## Checklist de Nivel 9

- [ ] ¿Sabes crear un proyecto con Maven?
- [ ] ¿Entiendes qué aporta Spring Boot?
- [ ] ¿Puedes exponer un endpoint REST simple?
- [ ] ¿Sabes conectar una entidad con una base de datos?
- [ ] ¿Puedes imaginar cómo se integra todo en una app real?

**Fin de la ruta:** ya tienes una base para construir aplicaciones Java completas.
