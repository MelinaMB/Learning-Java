# Learning-Java
Tutorial para aprender Java

## Ver la documentación con Docsify
Este proyecto incluye documentación estática en la carpeta `learning/`. Para verla de manera local con Docsify, sigue estos pasos:

1. Instala Node.js (si no lo tienes):
   - https://nodejs.org/
2. Abre una terminal en la carpeta del proyecto 
3. Instala docsify-cli globalmente:
   - `npm install -g docsify-cli`
4. Inicia el servidor local:
   - `docsify serve learning`
5. Abre en el navegador:
   - `http://localhost:3000`

> Cambia el puerto con `--port <puerto>` si ya está ocupado.
